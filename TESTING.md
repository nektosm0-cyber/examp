# Запуск и проверка

## Приложение

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000 (порт задаётся переменной `PORT`).

## Автотесты

```sh
npm test
```

или без npm:

```sh
node --test
```

Тест сам поднимает сервер на свободном порту. Он проверяет:

- успешный разбор с темой и непустым черновиком;
- HTTP 400 и `{"status":"invalid_input"}` для пустого, отсутствующего, нестрокового и битого ввода;
- `manual_review` с `topic: null` и `draft: null` для ошибки модели, битого JSON, недопустимой темы и пустого черновика;
- прерывание зависшего ответа модели за 300 мс.

## Польза для менеджера

Менеджер получает тему и готовый черновик, а не пишет первый ответ с нуля. При сбое модели интерфейс явно показывает «Нужен ручной разбор» и очищает предыдущий черновик, поэтому клиенту не уйдёт устаревший или пустой автоответ. Эффект можно измерить по среднему времени до первого ответа и по доле заявок, отправленных без ручной правки черновика.
